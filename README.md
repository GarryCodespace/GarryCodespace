# Garry Yuan

My life goal is to explore the potentialities of intelligence.

I like understanding how things work from the ground up, whether it's a circuit, a control loop, or a model that learns. My interests span electrical engineering, physics, mathematics, AI, and robotics. I learn from first principles by building small versions, testing them, and following one question into the next.

## Selected Projects

- **[NanoGPT Transformer Notebook](https://github.com/GarryCodespace/NanoGPT-/blob/main/nanoGPT.ipynb)** - A character-level GPT notebook in PyTorch, exploring tokenisation, causal self-attention, and text generation on Tiny Shakespeare.
- **[Minimal Coding Agent](https://github.com/GarryCodespace/firstagent)** - An educational Python agent that inspects files, edits code, runs tests, and iterates on feedback using OpenAI tool calls.
- **[Table-Tennis Editing Skill](https://github.com/GarryCodespace/table-tennis-editing-skill)** - A Python and FFmpeg workflow for cutting match recordings into complete rallies using visually reviewed timestamps.
- **[Machine Learning Project Lab](https://github.com/GarryCodespace/Machine_learning)** - Experiments spanning regression, classification, neural networks, computer vision, and language models, using NumPy and PyTorch.
- **[Soccer Match Predictor](https://github.com/GarryCodespace/Soccer_predictor_ml)** - A football prediction project exploring historical results, rolling team form, feature engineering, and leakage-safe evaluation.
- **[ANN for MOSFET SPICE Model Extraction](https://github.com/GarryCodespace/ANN-Mosfet)** - A PyTorch surrogate model that learns MOSFET behaviour from simulated current-voltage sweeps as a first step toward model extraction.
